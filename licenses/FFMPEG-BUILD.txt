FFmpeg in rega

rega's release binaries statically link FFmpeg's libavformat, libavcodec,
libswscale and libavutil. FFmpeg is under the GNU Lesser General Public License,
version 2.1 or later (LGPL-2.1.txt). It is built without --enable-gpl or
--enable-nonfree.


Source

  Version   9.0.1
  Tarball   ffmpeg-9.0.1.tar.xz, attached to every rega release:
            https://github.com/Elyg/rega/releases
  Origin    https://ffmpeg.org/releases/ffmpeg-9.0.1.tar.xz
  SHA-256   cf38e0e28c7e5605942c4a77755349b0145804a397af37eb1fb4c77cb237f635
  Changes   None. rega applies no patches to FFmpeg.


Linux, built with Nix (nix/package.nix)

  ./configure
    --arch=<x86_64 or aarch64> --target_os=linux --cc=<cross compiler>
    --pkg-config=pkg-config --enable-pic
    --enable-cross-compile --cross-prefix=<target> --host-cc=<build compiler>
    --disable-autodetect --disable-everything --disable-programs --disable-doc
    --disable-network --disable-avdevice --disable-avfilter --disable-swresample
    --enable-zlib --enable-demuxer=mov --enable-protocol=file
    --enable-decoder=h264,hevc,prores,dnxhd,mjpeg,mpeg2video,mpeg4,png,qtrle,rawvideo,v210,vp9
    --enable-parser=h264,hevc,mjpeg,mpeg4video,mpegvideo,vp9


macOS, built with Conan (conanfile.py and ConanCenter's ffmpeg/9.0.1 recipe)

  ./configure
    --disable-shared --enable-static --enable-pic --enable-asm --arch=aarch64
    --disable-cross-compile --disable-programs --disable-doc
    --disable-gpl --disable-nonfree
    --enable-avcodec --enable-avformat --enable-swscale
    --disable-avdevice --disable-avfilter --disable-swresample
    --enable-zlib --disable-bzlib --disable-lzma --disable-iconv
    --disable-appkit --disable-avfoundation --disable-coreimage
    --disable-audiotoolbox --disable-videotoolbox --disable-securetransport
    --disable-vulkan
    --disable-everything --enable-demuxer=mov --enable-protocol=file
    --enable-decoder=h264 --enable-decoder=hevc --enable-decoder=prores
    --enable-decoder=dnxhd --enable-decoder=mjpeg --enable-decoder=mpeg2video
    --enable-decoder=mpeg4 --enable-decoder=png --enable-decoder=qtrle
    --enable-decoder=rawvideo --enable-decoder=v210 --enable-decoder=vp9
    --enable-parser=h264 --enable-parser=hevc --enable-parser=mjpeg
    --enable-parser=mpeg4video --enable-parser=mpegvideo --enable-parser=vp9

  The recipe also passes --disable for each external library it can use, all of
  them off here; conanfile.py lists them.


Using a modified FFmpeg

rega's source is at https://github.com/Elyg/rega. To rebuild it against your own
FFmpeg, point nix/ffmpeg-source.nix at your source and run `nix build .#static`
on Linux, or replace the Conan package and run `just package` on macOS.
