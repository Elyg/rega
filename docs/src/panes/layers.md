> shows that layer.

{{#include ../reference/keys.md:pane-layers}}

## The list

Every layer of the current image, with its channels: `rgba` first, then the rest
alphabetically. `j` / `k` move and show each layer as you go, the same as `[` / `]` in
the viewer.

How channels group into layers, and `t` to tile them all: see
[Layers in the viewer](../viewer/image.md#layers).
